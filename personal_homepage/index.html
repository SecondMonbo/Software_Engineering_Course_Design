#

代码量统计工具

Python命令行 + 图形界面统计报表导出

输入本地文件夹或 GitHub 仓库链接，递归统计 35+ 种语言的代码行 / 注释行 / 空行，并支持函数级统计与 JSON、TXT、DOCX 结果导出。

获取启动器

该程序为桌面应用（需本机安装 Python 3）：点击“获取启动器”下载 run_gui.bat 后， 将其放入 code_count 文件夹双击即可打开图形界面；或在命令行中运行 python code_counter_ui.py。
