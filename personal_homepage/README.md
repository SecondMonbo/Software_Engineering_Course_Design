# personal_homepage — 小组个人主页

小组主页单页应用（单文件 HTML，零依赖），介绍小组成员并汇总本仓库三个课程项目的入口。

## 使用方法

双击打开 `index.html` 即可。主页通过相对路径 `../<项目目录>/index.html` 打开各项目，
请保持本文件夹与 `code_count`、`four_fundamental_oprations`、`throw_dice` 同级。

- 四则运算出题、掷骰子游戏：点击"打开运行"直接在浏览器中运行
- 代码量统计工具：桌面程序（需 Python 3），主页提供 `run_gui.bat` 启动器下载与运行命令复制
